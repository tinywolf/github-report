# 깃헙 주간 트렌드 리포트

## 작업 흐름
1. 깃헙 주간 트렌드 페이지(https://github.com/trending?since=weekly)를 조회.
  1. 브라우저 에이전트를 사용하지 말고 curl 명령어를 사용할 것.
2. 깃헙 주간 트렌드 페이지의 내용을 분석.
3. 리포트 작성 규칙에 따라 리포트를 작성. 리포트 형식 제약 사항을 지켜야 함.
4. 리포팅 결과를 `weekly-trend` 디렉토리에 `yyyy-mm-dd.md` 파일로 저장. 파일명 내 `yyyy-mm-dd` 는 현재 날짜를 기입.
5. 리포트 결과 파일이 형식 제약 사항을 위반하는지 검증.
6. 형식 제약 사항을 위반하는 경우, 형식 제약 사항을 지켜서 리포트를 수정.
7. 작업 중 생성한 임시 파일 삭제.

## 리포트 작성 규칙
1. 개요
  1. 리포지토리 내용을 참고하여, 트렌드를 분석한 결과를 제공합니다.
2. 리포지토리
  1. 상위 리포지토리 목록을 제공합니다. 깃헙 주간 트렌드 페이지에서 제공하는 리포지토리 목록을 모두 나열하세요. 임의로 누락하거나 추가하면 안됩니다.
  2. 목록은 리포지토리 이름, 언어, 누적 ★, 주간 ★, 요약으로 구성합니다.
  3. 요약은 한국어로 작성하세요.
3. 주요 리포지토리 분석
  1. 주목할만한 리포지토리를 몇 개 선정하고, 그에 대한 자세한 내용을 제공합니다.
  2. 필요하다면 각 리포지토리의 README.md 페이지를 조회하고 내용을 분석하세요.
    1. README.md 에서 주목해야 하는 내용은 리포지토리 설명, 사용 또는 개발 목적, 주요 기능입니다. 실행 방법이나 예시, 설정 등은 분석하지 않습니다.
  3. 분석 내용은 한국어로 작성하세요.

## 리포트 형식 제약 사항
1. markdown 으로 작성합니다.
2. resources/report-format.md 파일을 참고하여 리포트를 작성하세요.
  1. 제한된 문법만 사용해야 합니다.
    1. H1 (#), H2 (##)
    2. bold (*), italic (_)
    3. hyperlink ([text](url))
    4. 인용 (>), 코드 블록(```)
  2. 제한된 문법 외의 문법은 사용할 수 없습니다.
