# GitHub 주간 트렌드 리포트 (2026-07-22)

## 1. 개요
이번 주 트렌드는 AI 코딩 에이전트의 품질, 병렬 실행, 컨텍스트 효율을 높이는 도구가 중심을 이뤘다.  
에이전트가 코드베이스를 더 적게 읽고도 정확하게 작업하도록 돕는 그래프, 스킬, CLI, 통합 개발 환경이 다수 주목받았다.  
동시에 생성형 UI의 획일성을 줄이는 디자인 스킬과 AI 에이전트가 문서 파일을 직접 다루게 하는 도구가 부상해, 개발 자동화의 적용 범위가 코드 밖으로 넓어지고 있다.

## 3. 주요 리포지토리 분석

_[Nutlope/hallmark](https://github.com/Nutlope/hallmark)_

Hallmark는 AI가 만든 화면에서 자주 보이는 정형화된 구조와 스타일을 줄이는 데 초점을 둔 디자인 스킬이다. 작업 요구에 맞춰 거시적 레이아웃과 테마를 선택하고, 57개 품질 검사와 사전 자기 검토로 결과물을 평가한다. 새 UI 생성뿐 아니라 기존 코드 감사, 구조를 새로 만드는 리디자인, 참고 화면의 구조·타이포그래피·색상 체계 분석을 지원해 디자인 품질을 에이전트 워크플로의 명시적인 단계로 만든다.

_[tirth8205/code-review-graph](https://github.com/tirth8205/code-review-graph)_

code-review-graph는 대규모 저장소를 통째로 다시 읽는 AI 코드 리뷰의 비용과 정확도 문제를 해결한다. Tree-sitter로 함수, 클래스, 임포트, 호출 관계, 테스트 범위를 그래프로 만들고, 변경 영향 범위에 맞는 최소 파일 집합을 MCP를 통해 에이전트에 전달한다. 변경분만 다시 분석하는 증분 갱신과 위험도 기반 PR 분석을 제공하며, 코드 유출 없이 로컬과 CI 환경에서 작동하도록 설계된 점이 특징이다.

_[stablyai/orca](https://github.com/stablyai/orca)_

Orca는 Codex, Claude Code, OpenCode, Pi 등 터미널 기반 에이전트를 하나의 작업 공간에서 조율하는 개발 환경이다. 동일한 요청을 독립 Git 워크트리의 여러 에이전트에 병렬로 맡기고 결과를 비교·병합할 수 있으며, 원격 SSH 워크트리와 모바일 동반 앱도 지원한다. 브라우저 UI 요소를 에이전트 문맥으로 전달하는 디자인 모드, AI 생성 변경분에 대한 주석, GitHub와 Linear 작업 연동까지 포함해 에이전트 실행과 검토의 단절을 줄인다.

```
생성 모델: gpt-5.6-terra
추론 수준: medium
```
