# GitHub 주간 트렌드 리포트 (2025-12-10)

## 1. 개요
- 대형 인프라·데이터 프로젝트(rustfs)가 최고 주간 스타를 기록하며 클라우드 스토리지 성능 경쟁이 부각됐습니다.

- 기존 메인스트림 런타임·프레임워크(bun, react, next.js)도 꾸준히 관심을 받으며 안정적 수요를 확인했습니다.

## 3. 주요 리포지토리 심층 분석

*[rustfs/rustfs](https://github.com/rustfs/rustfs)*
- README에 따르면 Rust 구현으로 4KB 객체에서 MinIO 대비 2.3배 속도를 강조하며, S3 호환성과 데이터 레이크·AI 워크로드 최적화를 내세워 성능 지표에 민감한 기업·커뮤니티 관심을 끌었습니다.
- Apache 2.0 라이선스와 분산 모드·버전닝·레플리케이션을 포함한 기능 로드맵을 명시해 상용·자체 호스팅 채택 장벽을 낮춘 점이 빠른 스타 상승의 핵심 요인입니다.

*[DayuanJiang/next-ai-draw-io](https://github.com/DayuanJiang/next-ai-draw-io)*
- 자연어 프롬프트로 draw.io XML을 생성·편집하고, 이미지 기반 다이어그램 복제·버전 히스토리·AWS/GCP/Azure 아이콘 지원 등 업무용 기능이 풍부해 "AI+시각화" 수요를 정확히 겨냥했습니다.
- Docker 배포 예시, 멀티 프로바이더(Claude, OpenAI, Bedrock 등) 설정 가이드, 오프라인 배포 안내까지 제공해 실사용 장벽을 낮춘 것이 주간 3,800★ 급증으로 연결된 것으로 보입니다.

*[lfnovo/open-notebook](https://github.com/lfnovo/open-notebook)*
- Notebook LM 대안으로, 16+ 모델 지원·로컬/자체 호스팅·다중 모달 콘텐츠 관리·멀티 화자 팟캐스트 생성·벡터+전문 검색을 강조해 프라이버시와 비용 통제 니즈를 겨냥했습니다.
- v1.0 전환 공지(React/Next.js 프런트, FastAPI 백엔드, 필수 포트 5055 노출 등)와 상세 Docker/Compose 예시가 제공돼 커뮤니티 재배포 및 자가 구축 모멘텀을 강화했습니다.
