# GitHub 주간 트렌드 리포트 (2026-01-14)

## 1. 개요
- AI 코딩 에이전트·개발 워크플로 자동화 도구가 상위권을 거의 독식해 주간 스타 수 급증이 에이전트 생태계 확산을 반영함.
- 주요 언어는 TypeScript와 Shell로, 터미널·CLI 중심 배포와 확장성 높은 플러그인 구조가 공통 특징으로 나타남.
- 기존 인기 OSS(웹 보안 점검, 멀티모달 에이전트, 멀티에이전트 협업)가 꾸준히 주간 유입을 이어가며 실사용 사례가 늘어나는 흐름.

## 3. 주요 리포지토리 분석

*[anomalyco/opencode](https://github.com/anomalyco/opencode)*
- 디폴트 브랜치 `dev`에서 유지되며, CLI·데스크톱 모두 지원하고 provider-agnostic 설계를 강조해 다양한 모델(Claude·OpenAI·Google·로컬)과 호환됨 ([README](https://raw.githubusercontent.com/anomalyco/opencode/dev/README.md)).
- 설치 경로를 `OPENCODE_INSTALL_DIR` 등 환경변수 우선순위로 제어해 서버·로컬 양쪽에서 배포 편의성을 높였고, 빌트인 `build/plan` 에이전트로 안전한 실행 모드를 분리.

*[anthropics/claude-code](https://github.com/anthropics/claude-code)*
- 터미널·IDE 통합형 에이전틱 코딩 도구로, 공식 문서에서 npm 설치를 중단하고 전용 설치 스크립트·GUI 배포를 권장하며 플러그인 마켓을 통해 명령 확장이 가능함 ([README](https://github.com/anthropics/claude-code/blob/main/README.md)).
- 자연어로 Git 워크플로·코드 설명·루틴 작업 실행을 통합해 “코드 이해→편집→테스트”를 단일 인터페이스에서 처리하도록 설계.

*[obra/superpowers](https://github.com/obra/superpowers)*
- Claude Code·Codex·OpenCode에서 자동으로 활성화되는 스킬 모음으로, 설계 검증→TDD→계획 실행→코드 리뷰까지 강제하는 절차형 가드레일을 제공 ([README](https://github.com/obra/superpowers/blob/main/README.md)).
- `/superpowers:write-plan`, `/execute-plan` 등 명령형 인터페이스로 소형 태스크 단위 실행과 병렬 서브에이전트 전략을 지원해 장시간 자율 작업을 목표로 함.

*[bytedance/UI-TARS-desktop](https://github.com/bytedance/UI-TARS-desktop)*
- 멀티모달 GUI 에이전트 스택으로, 로컬/원격 컴퓨터·브라우저 오퍼레이터를 통해 UI 자동화를 실행하고 AIO agent Sandbox 연동으로 격리된 도구 실행을 지원 ([README](https://github.com/bytedance/UI-TARS-desktop/blob/main/README.md)).
- 최신 릴리스(예: v0.3.0)에서 멀티툴 스트리밍, 이벤트 스트림 뷰어, 런타임 설정 UI 등을 추가하며 데스크톱 앱을 생산용으로 고도화.

*[Lissy93/web-check](https://github.com/Lissy93/web-check)*
- 웹 보안/인프라 진단 대시보드로, DNS·SSL·포트·리다이렉트·추적기 등 다중 체커를 한 번에 실행하며 호스팅 데모와 여러 배포 옵션(Netlify/Vercel/Docker)을 제공 ([README](https://github.com/Lissy93/web-check/blob/master/.github/README.md)).
- 오픈소스 인텔리전스(OSINT)와 보안 점검을 통합 제공해, 운영 중인 사이트의 설정·취약점·성능을 즉시 파악하려는 운영자 수요가 주간 별점 상승으로 이어진 것으로 해석됨.
