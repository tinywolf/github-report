# GitHub 주간 트렌드 리포트 (2026-04-08)

## 1. 개요
이번 주 GitHub 주간 트렌드는 _AI 코딩 에이전트를 더 길게, 더 체계적으로 운용하려는 흐름_이 가장 강하게 드러났습니다. [Yeachan-Heo/oh-my-codex](https://github.com/Yeachan-Heo/oh-my-codex), [luongnv89/claude-howto](https://github.com/luongnv89/claude-howto), [Yeachan-Heo/oh-my-claudecode](https://github.com/Yeachan-Heo/oh-my-claudecode), [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)처럼 에이전트의 프롬프트, 워크플로, 팀 실행 구조를 다루는 저장소가 상위권을 차지했습니다. 단순히 모델 성능을 비교하는 단계를 넘어, _반복 가능한 실행 체계_와 _협업 가능한 작업 환경_에 관심이 집중된 모습입니다.

동시에 이번 주 목록은 _창작 도구와 실용형 AI 제품_도 함께 끌어올렸습니다. [siddharthvaddem/openscreen](https://github.com/siddharthvaddem/openscreen)은 유료 스크린 데모 도구를 대체할 수 있는 오픈소스 제작 도구로 주목받았고, [microsoft/VibeVoice](https://github.com/microsoft/VibeVoice)와 [onyx-dot-app/onyx](https://github.com/onyx-dot-app/onyx)는 각각 음성 AI와 업무형 AI 플랫폼 수요를 반영했습니다. 이번 트렌드는 _개발자용 에이전트 인프라_와 _바로 써볼 수 있는 완성형 도구_가 동시에 성장하고 있음을 보여줍니다.

또 하나의 특징은 _전문화된 데이터·리서치 자산의 부상_입니다. [google-research/timesfm](https://github.com/google-research/timesfm)은 시계열 예측용 파운데이션 모델을 전면에 내세웠고, [asgeirtj/system_prompts_leaks](https://github.com/asgeirtj/system_prompts_leaks), [sherlock-project/sherlock](https://github.com/sherlock-project/sherlock)은 각각 프롬프트 연구와 OSINT 탐색 수요를 끌어왔습니다. 이번 주 트렌드는 결국 범용 AI 열풍이 여전히 중심이지만, 그 위에서 _특정 업무를 더 잘 처리하는 전문 도구_가 빠르게 존재감을 키우고 있다는 신호로 읽힙니다.

## 3. 주요 리포지토리 분석
*[Yeachan-Heo/oh-my-codex](https://github.com/Yeachan-Heo/oh-my-codex)*

이 저장소는 Codex를 대체하는 제품이 아니라, Codex 위에 _더 강한 기본 세션 구성과 작업 절차_를 얹는 워크플로 계층에 가깝습니다. 시작 단계의 질의 정리, 계획 승인, 지속 실행, 팀 단위 병렬 처리 같은 흐름을 명시된 명령 체계로 묶어 두었고, 프로젝트별 상태를 `.omx/` 아래에 유지하도록 설계했습니다. 이번 주 상위권에 오른 이유는 코딩 에이전트를 단순 호출형 도구가 아니라 _운영 가능한 개발 환경_으로 다루려는 수요와 정확히 맞물리기 때문입니다.

*[siddharthvaddem/openscreen](https://github.com/siddharthvaddem/openscreen)*

OpenScreen은 유료 제품군이 장악하던 데모 영상 제작 영역에서 _무료이면서 상업적으로도 사용할 수 있는 실용 도구_를 제시합니다. 특정 창 또는 전체 화면 녹화, 자동 또는 수동 줌, 배경 구성, 주석 추가, 구간 편집, 다양한 비율로의 내보내기처럼 사용자가 실제로 필요로 하는 핵심 기능을 빠르게 제공하는 데 초점이 맞춰져 있습니다. 이번 상승은 개발자 커뮤니티가 AI 도구뿐 아니라 _콘텐츠 제작 생산성을 높여 주는 오픈소스 완성품_에도 즉각 반응하고 있음을 보여줍니다.

*[google-research/timesfm](https://github.com/google-research/timesfm)*

TimesFM은 시계열 예측을 범용 모델이 아닌 _전용 파운데이션 모델_로 다루는 방향을 분명하게 보여줍니다. 최신 공개 버전은 더 긴 문맥 길이와 연속적 분위수 예측 같은 기능을 전면에 내세우며, 연구 저장소에서 끝나지 않고 Hugging Face 배포와 BigQuery 연계까지 이어지는 생태계를 갖췄습니다. 이번 주 트렌드 안에서 이 프로젝트가 눈에 띄는 이유는, 생성형 AI 관심이 여전히 강한 와중에도 _도메인 특화 모델을 실제 분석 업무에 연결하려는 흐름_이 분명히 살아 있음을 보여주기 때문입니다.
