## 1. 개요
이번 주 트렌드는 코딩 에이전트의 작업 품질과 지속성을 높이는 스킬, 메모리, 컨텍스트 관리 도구에 강하게 집중되어 있다.

## 3. 주요 리포지토리 분석
> **[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)**  
> 에이전트가 작업 경험으로부터 스킬을 만들고 사용 중 개선하며, 대화 기록 검색과 사용자 모델을 통해 세션을 넘는 연속성을 구축한다. 여러 모델 제공자를 교체해 사용할 수 있고, 단일 게이트웨이로 메신저와 CLI를 연결한다. 예약 자동화, 격리된 하위 에이전트, 다양한 실행 백엔드를 함께 제공해 개인 비서부터 클라우드 작업 자동화까지 포괄한다.
>  
> **[affaan-m/ECC](https://github.com/affaan-m/ECC)**  
> 코딩 에이전트가 계획, 테스트, 구현, 검토, 검증, 기억, 개선을 순환하도록 만드는 엔지니어링 운영 체계다. 전문 역할의 에이전트와 광범위한 스킬, 규칙, 훅, 보안 검사 기능을 결합해 반복되는 성공 패턴을 재사용 가능한 워크플로로 전환한다. 다양한 코딩 에이전트 환경에 맞춘 지원 경로를 제공하는 점에서, 단일 모델의 능력보다 실행 프로세스의 품질을 높이려는 흐름을 잘 보여 준다.
>  
> **[microsoft/markitdown](https://github.com/microsoft/markitdown)**  
> PDF, 오피스 문서, 이미지, 오디오, HTML, 데이터 형식, 압축 파일, 동영상 URL 등 다양한 입력을 LLM과 텍스트 분석 파이프라인에 적합한 Markdown으로 바꾼다. 제목·표·링크 같은 문서 구조와 핵심 내용을 보존하는 데 중점을 두며, 플러그인과 선택적 의존성으로 형식별 변환 능력을 확장한다. 에이전트가 비정형 자료를 읽고 활용하는 과정의 표준 입력 계층으로서 높은 실용성을 가진다.

```
생성 모델: gpt-5.6-terra
추론 수준: medium
```
