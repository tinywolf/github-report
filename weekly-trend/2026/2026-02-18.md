# GitHub 주간 트렌드 리포트 (2026-02-18)

## 1. 개요
이번 주 트렌드는 _에이전트 실무화_가 핵심입니다. 브라우저 제어, 보안 점검, 정보 추출, 워크플로우 자동화처럼 바로 운영에 붙일 수 있는 저장소가 상위권을 차지했습니다.
또한 *개발 생산성 도구와 에이전트 인프라*가 함께 성장하고 있습니다. 단일 모델 성능보다, 실제 업무 맥락에서 재현성과 운영 안전성을 확보하는 방향이 강화되었습니다.
마지막으로 *도메인 특화 에이전트*가 뚜렷합니다. 금융 트레이딩, 요약/오피스 자동화, 프런트엔드 UI 생성 등 세부 업무별 최적화 프로젝트가 빠르게 확산 중입니다.

## 3. 주요 리포지토리 분석

*[google/langextract](https://github.com/google/langextract)*
LangExtract는 사용자 지시와 예시를 기반으로 비정형 문서에서 구조화 데이터를 뽑고, 추출 결과를 원문 위치와 연결해 검증 가능성을 높이는 데 초점을 둡니다. README 기준 핵심 가치는 근거 추적, 일관된 스키마 출력, 장문 문서 처리를 위한 청킹/병렬/다중 패스 전략, 그리고 인터랙티브 시각화입니다. 즉, 추출 정확도뿐 아니라 _감사 가능성_을 함께 제공하는 데이터 추출 파이프라인에 가깝습니다.

*[ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)*
이 프로젝트는 코딩 에이전트가 MCP를 통해 실행 중인 Chrome을 직접 관찰·제어하도록 만들어, 성능 트레이스 분석과 네트워크/콘솔 디버깅을 자동화합니다. README에서 강조하는 포인트는 DevTools 기반 성능 인사이트, Puppeteer 기반 안정적 자동화, 그리고 민감 데이터 노출 가능성에 대한 운영상 주의사항입니다. 에이전트 개발에서 브라우저 검증 단계를 표준 워크플로우로 끌어올리는 성격이 강합니다.

*[KeygraphHQ/shannon](https://github.com/KeygraphHQ/shannon)*
Shannon은 “경고”가 아닌 _재현 가능한 실제 익스플로잇_ 보고를 목표로 하는 자율형 웹 보안 에이전트입니다. README에 따르면 코드 기반 공격 벡터 탐색 후 내장 브라우저로 공격을 실행해 취약점 악용 가능성을 증명하며, 펜테스트 주기 공백을 상시 자동 점검으로 메우는 것이 핵심 목적입니다. 보안팀 관점에서는 거짓 양성 축소와 실전 대응 속도 향상에 직접 연결되는 접근입니다.

*[github/gh-aw](https://github.com/github/gh-aw)*
GitHub Agentic Workflows는 자연어 마크다운으로 워크플로우를 정의하고 GitHub Actions에서 실행하는 방식을 제시합니다. README 핵심은 기본 읽기 전용 권한, safe-outputs를 통한 제한적 쓰기, 샌드박스 실행 및 검증 계층 같은 가드레일입니다. 에이전트 자동화가 확대되는 상황에서 _운영 안전성과 통제 가능성_을 함께 설계한 레퍼런스라는 점이 주목 포인트입니다.
