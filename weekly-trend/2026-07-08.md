# GitHub 주간 트렌드 리포트 (2026-07-08)

## 1. 개요

이번 주 트렌드는 AI 에이전트가 개발, 보안, 회의 기록, 채용, 투자 리서치, 영상 편집 같은 실제 업무 흐름에 깊게 들어가는 방향이 강합니다. 단일 모델이나 데모보다, 기존 도구와 연결되어 반복 업무를 수행하는 실행 계층이 주목받고 있습니다.

보안 자동화와 코드베이스 이해 도구의 존재감이 특히 큽니다. Strix, codebase-memory-mcp, chrome-devtools-mcp, CubeSandbox처럼 에이전트가 애플리케이션을 검사하고, 실행 환경을 다루고, 코드 구조를 기억하게 만드는 프로젝트가 상위권에 여럿 배치되어 있습니다.

로컬 실행과 데이터 주권도 중요한 흐름입니다. Meetily, FluidVoice, codebase-memory-mcp는 민감한 회의, 음성, 코드 정보를 외부 서비스로 보내지 않고 처리하려는 요구를 반영합니다.

## 3. 주요 리포지토리 분석

_[usestrix/strix](https://github.com/usestrix/strix)_

Strix는 AI 에이전트를 침투 테스트 담당자로 구성해 정찰, 취약점 탐색, 익스플로잇 검증, 수정 제안까지 이어지는 보안 워크플로를 자동화합니다. 정적 분석의 경고 나열보다 실제 PoC 검증과 재현 가능한 결과를 강조한다는 점에서 개발팀과 보안팀 모두를 겨냥합니다.

주요 기능은 다중 에이전트 오케스트레이션, 브라우저 기반 취약점 테스트, 셸 실행, HTTP 요청 분석, OWASP Top 10 범주의 취약점 탐색입니다. 이번 주 가장 높은 주간 스타를 기록한 것은 AI 에이전트가 단순 코드 작성 보조를 넘어 보안 검증과 DevSecOps 파이프라인으로 확장되고 있음을 보여줍니다.

_[Zackriya-Solutions/meetily](https://github.com/Zackriya-Solutions/meetily)_

Meetily는 회의 내용을 로컬에서 캡처하고 실시간 전사와 요약을 생성하는 프라이버시 중심 회의 도우미입니다. 회의 데이터가 외부 클라우드로 나가지 않는 구조를 강조하며, 기업과 전문직 사용자가 민감한 대화의 통제권을 유지하는 데 초점을 둡니다.

주요 기능은 Whisper 또는 Parakeet 기반 로컬 전사, 실시간 회의 기록, Ollama 같은 로컬 모델 및 OpenAI 호환 엔드포인트를 통한 요약, macOS와 Windows 중심의 데스크톱 사용성입니다. 회의 AI가 보편화되는 흐름 속에서 데이터 주권과 온디바이스 처리가 차별점으로 떠오르는 사례입니다.

_[DeusData/codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp)_

codebase-memory-mcp는 코드베이스를 빠르게 색인해 함수, 클래스, 호출 관계, 라우트, 서비스 연결을 지속적인 지식 그래프로 저장합니다. AI 코딩 에이전트가 파일을 하나씩 읽는 방식에서 벗어나 구조 검색, 아키텍처 이해, 영향 분석을 MCP 도구로 바로 수행하도록 돕습니다.

주요 기능은 158개 언어에 대한 tree-sitter 기반 파싱, 일부 언어의 LSP 의미 분석, 코드 검색과 그래프 검색, 아키텍처 요약, 변경 영향 분석, 크로스 서비스 연결 탐지입니다. 단일 정적 바이너리와 로컬 처리를 내세우는 점도 코드 보안과 도입 편의성을 중시하는 팀에게 중요한 장점입니다.
