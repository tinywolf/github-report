## 3. 주요 리포지토리 심층 분석

### [sansan0/TrendRadar](https://github.com/sansan0/TrendRadar)
- README에 따르면 35개 이상의 뉴스·SNS 플랫폼을 크롤링하고, 13개 MCP 도구로 추세 추적·감성 분석·유사 뉴스 검색을 자연어 질의로 수행할 수 있습니다.
- 2025/11 릴리스에서 Slack·Bark 등 신규 채널과 Markdown 알림 최적화를 추가하면서 “30초 GitHub Pages 배포 + 1분 모바일 알림” 경험을 강조합니다.
- 키워드 필터(필수·제외·우선순위·개수)와 시간창 기반 푸시 제어로 PR·IR·투자 등 팀별 요구에 맞춘 경보 정책을 구성할 수 있습니다.
- GitHub Actions, Docker, 로컬 등 다중 배포 경로와 테스트 데이터(11/1~15) 제공 덕택에 데이터 팀이 빠르게 PoC를 수행하기 좋습니다.

### [usestrix/strix](https://github.com/usestrix/strix)
- “Open-source AI Hackers”라는 포지셔닝처럼 Agent 팀이 실제 해커 도구(HTTP Proxy, 브라우저, 쉘, Playwright 등)를 실행해 IDOR, SSRF, XSS, 비즈니스 로직 취약점을 검증합니다.
- `pipx install strix-agent` 후 `strix --target ./service`만으로 오프라인 스캔이 가능하며, GitHub Actions 워크플로 예시도 제공해 PR 기반 차단(Non-zero exit on vulns)을 쉽게 붙일 수 있습니다.
- OpenAI/GPT-5, Claude Sonnet 4.5, 로컬 LLM 등 다양한 백엔드를 환경 변수로 전환할 수 있어 비용·보안 정책에 따라 유연하게 구성됩니다.
- README는 호스티드 SaaS도 소개하며, 자동 보고서·대시보드·CI 연계를 통해 빠른 펜테스트 주기로 전환하라는 메시지를 전달합니다.

### [666ghj/BettaFish](https://github.com/666ghj/BettaFish)
- Query/Media/Insight/Report 네 개의 핵심 Agent와 ForumEngine 중재자가 토론하며 단계별로 검색→분석→보고서(IR→HTML/PDF)를 생성합니다.
- MindSpider 크롤러는 24/7로 30+ 국내외 플랫폼과 수백만 댓글을 수집하며, Insight Agent는 사내 DB·감성 모델(BERT, Qwen 미세조정 등)을 연결해 내부 지표까지 엮을 수 있습니다.
- README는 “Forum” 구조, 다중 모달(단문·동영상·검색 카드) 처리, Bark/Slack/企业微信 알림 등 실전 시나리오를 자세히 설명해 커스터마이징 포인트를 명확히 제시합니다.
- 완성된 보고서는 템플릿 선택→레이아웃→챕터별 JSON IR→HTML/PDF 렌더링으로 이어져, 기업 브랜딩에 맞춘 결과물을 쉽게 재활용할 수 있습니다.

### [mudler/LocalAI](https://github.com/mudler/LocalAI)
- README는 LocalAI가 OpenAI 호환 REST API를 로컬에서 제공하며, 텍스트·이미지·오디오·비전·객체 탐지·MCP 등 다양한 기능을 동일 인터페이스로 노출한다고 밝힙니다.
- docker/installer/DMG 등 설치 옵션과 자동 백엔드 감지(LLM·Diffusers·Whisper·Bark 등)를 강조해 “GPU가 없어도 실행”이라는 메시지를 실현합니다.
- 2025년 릴리스 노트에는 Slack/Telegram 봇, LocalAGI/LocalRecall 연동, P2P 분산 추론, MCP 지원 등 생태계 확장 소식이 나열되어 있습니다.
- 로드맵과 풍부한 하드웨어 매트릭스(CUDA, ROCm, Intel, Metal, Vulkan 등)를 통해 엔터프라이즈 또는 엣지 환경에서 정책 제약 없이 LLM을 운용하려는 팀에게 매력적인 대안을 제공합니다.
