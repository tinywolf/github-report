## 3. 주요 리포지토리 분석

*[usememos/memos](https://github.com/usememos/memos)*
- README 기준 프라이버시 우선 아키텍처(무 테레메트리·완전한 데이터 소유)와 마크다운 네이티브 저장소를 강조하며, Docker 원라인 배포와 SQLite/MySQL/PostgreSQL 지원으로 개인·팀 배포 장벽을 낮춤([README](https://github.com/usememos/memos)).
- 주간 스타 4천+로 재택·자체 호스팅 노트 수요가 여전함을 보여주며, REST/gRPC API 제공으로 다른 지식 관리 워크플로우와의 통합성이 높음.

*[BloopAI/vibe-kanban](https://github.com/BloopAI/vibe-kanban)*
- 여러 코딩 에이전트(Claude Code, Gemini CLI 등)를 병렬/직렬로 실행·전환하고 작업 상태를 한 Kanban 보드에서 관리하는 Rust+Node 기반 오케스트레이션 도구로, 영상·문서 링크를 통해 운영 흐름을 제공([README](https://github.com/BloopAI/vibe-kanban/blob/main/README.md)).
- 주간 스타 5천+로 개발 자동화 운영층에 대한 니즈가 급증했음을 시사하며, SSH 원격 프로젝트 열기와 dev 서버 실행 지원으로 분산 협업·리모트 개발에 적합.

*[anomalyco/opencode](https://github.com/anomalyco/opencode)*
- 오픈소스 AI 코딩 에이전트(TUI/CLI)로 멀티 모델(Claude/OpenAI/로컬), LSP, 클라이언트-서버 구조를 지원해 원격·모바일 제어까지 염두에 둔 설계를 제공([README](https://github.com/anomalyco/opencode/blob/dev/README.md)).
- curl 스크립트·npm/패키지 매니저 설치, 데스크톱 앱 베타까지 폭넓은 배포 채널을 갖추었으며, build/plan 에이전트 분리로 안전한 코드 탐색과 쓰기 작업을 구분해 실무 적용성을 높임.
