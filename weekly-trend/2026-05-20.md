## 3. 주요 리포지토리 분석

_[mattpocock/skills](https://github.com/mattpocock/skills)_
- 이 프로젝트는 AI 코딩 에이전트가 실제 엔지니어링 문제를 다룰 때 반복적으로 겪는 정렬 실패, 과도한 장황함, 피드백 루프 부족, 설계 품질 저하를 줄이는 데 초점을 둡니다.
- 스킬은 거대한 절차 프레임워크보다 작고 조합 가능한 단위로 구성되어 있어, 팀이나 개인의 기존 개발 방식에 맞춰 골라 쓰기 쉽습니다.
- 핵심 기능은 요구사항을 깊게 묻는 세션, 도메인 용어 정리, 테스트 주도 개발, 체계적 디버깅, 아키텍처 개선, 이슈와 PRD 생성 등 개발 전 과정에 걸친 에이전트 행동 지침입니다.

_[tinyhumansai/openhuman](https://github.com/tinyhumansai/openhuman)_
- OpenHuman은 개인의 이메일, 문서, 캘린더, 저장소, 메시지 같은 업무 데이터를 로컬 지식 기반으로 압축하고 기억하는 개인 AI 에이전트입니다.
- 데스크톱 중심 경험, 118개 이상의 외부 서비스 연동, 주기적 자동 동기화, SQLite와 Obsidian 호환 vault 기반의 메모리 트리를 결합해 에이전트가 장기 맥락을 유지하도록 설계되었습니다.
- 주요 기능은 로컬 우선 데이터 보관, OAuth 기반 서비스 연결, 코드와 검색 도구, 음성 기능, 작업별 모델 라우팅, 토큰 압축 계층이며, 개인 생산성 에이전트를 범용 업무 허브로 확장하려는 성격이 강합니다.

_[obra/superpowers](https://github.com/obra/superpowers)_
- Superpowers는 코딩 에이전트가 바로 구현에 뛰어들지 않고 목표 확인, 사양 정리, 구현 계획, 테스트 주도 개발, 리뷰, 브랜치 마무리를 순서대로 수행하도록 만드는 개발 방법론입니다.
- Claude Code, Codex, Cursor, OpenCode 등 여러 에이전트 환경에 설치할 수 있도록 구성되어 있으며, 특정 도구 하나보다 에이전트 작업 습관을 표준화하는 데 초점이 있습니다.
- 핵심 기능은 브레인스토밍, 작업 트리 분리, 세부 계획 작성, 서브에이전트 기반 실행, RED-GREEN-REFACTOR 루프, 코드 리뷰 요청, 개발 브랜치 마감 절차입니다.
