https://github.com/trending?since=weekly 페이지는 깃헙 주간 트렌드 페이지입니다.
이 페이지의 내용을 분석하고, 형식 제약 사항을 반드시 지켜서 리포트를 작성하세요.

## 리포트 형식 제약 사항
- markdown 으로 작성합니다.
- 제한된 문법만 사용해야 합니다.
  - H1 (#), H2 (##)
  - bold (*), italic (_)
  - hyperlink ([text](url))
  - 인용 (>), 코드 블록(```)
- 제한된 문법 외 다른 문법은 절대 사용하면 안됩니다.
- 리포팅 결과 중 리포지토리 이름은 클릭하면 리포지토리로 바로 이동할 수 있도록 링크를 추가하세요.

## 리포트 내용

1. 개요
  - 리포지토리 내용을 참고하여, 트렌드를 분석한 결과를 제공합니다.
2. 리포지토리
  - 상위 리포지토리 목록을 테이블 형식으로 제공합니다.
  - 테이블은 리포지토리 이름, 언어, 누적 ★, 주간 ★, 요약으로 구성합니다.
  - 요약은 한국어로 작성하세요.
3. 주요 리포지토리 심층 분석
  - 주목할만한 리포지토리를 몇 개 선정하고, 그에 대한 자세한 내용을 제공합니다.
  - 필요하다면 각 리포지토리의 README.md 페이지를 조회하고 내용을 분석하세요.
  - 분석 내용은 한국어로 작성하세요.

## 작업 요구사항

- 작업 중 생성하는 임시 파일은 작업을 완료 한 후 모두 삭제하세요.
- 리포팅 결과를 `weekly-trend` 디렉토리에 `yyyy-mm-dd.md` 파일로 저장하세요. 파일명 내 `yyyy-mm-dd` 는 현재 날짜를 기입해야 합니다.
